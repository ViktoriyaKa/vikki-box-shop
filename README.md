# Vikki Box Shop

Логотип и небольшая витрина бренда **Vikki Box Shop** — боксы с маленькими радостями для обычного дня.

Надпись на логотипе: *маленькие радости для твоего дня*.

## Как запустить

```bash
npm install
npm run dev
```

Сайт откроется на [http://localhost:43173](http://localhost:43173).
