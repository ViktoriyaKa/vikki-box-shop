# Vikki Box Shop

Сайт бренда подарочных боксов: витрина, каталог, история и форма заказа. Все фото, тексты и заявки живут **локально в проекте**, без облачного хранилища.

Локальная папка на компьютере Вики:

`C:\Users\Vika_2005\VikkiBox_Shop`

Скопируйте сюда этот репозиторий (или клонируйте git в эту папку) — сайт и картинки будут у вас на диске.

## Как запустить

```bash
cd C:\Users\Vika_2005\VikkiBox_Shop
npm install
npm run dev
```

Откройте [http://localhost:43173](http://localhost:43173).

## Что где лежит

| Путь | Что внутри |
| --- | --- |
| `public/brand/` | Логотип |
| `public/hero/` | Шапка и обложка |
| `public/products/` | Фото боксов |
| `public/stories/` | Сторис: форма заказа и прайс |
| `src/data/products.ts` | Названия, цены, состав |
| браузер, localStorage | Заявки с страницы «Заказать» |

Новый бокс: добавьте картинку в `public/products/` и карточку в `src/data/products.ts`.
